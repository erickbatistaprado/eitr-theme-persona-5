# Persona 5 theme for Eitr

A dark [Eitr](https://eitr.info) theme with Persona 5 art: Phantom Thieves red on black, with 7 wallpapers.

![Preview](persona-5/preview.png)

## Install

Open the Eitr Store, choose Themes, and search for Persona 5.
